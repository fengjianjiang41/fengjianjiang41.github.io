# fengjianjiang41.github.io

My personal homepage, built automatically by GitHub Pages (Jekyll).

## Editing

You can edit everything on github.com with the pencil icon. Each commit rebuilds the site in about a minute.

| What                         | File                      |
|------------------------------|---------------------------|
| Name, tagline, email         | `_config.yml`             |
| About text                   | `index.md`                |
| Education / career path      | `_data/path.yml`          |
| Projects                     | `_data/projects.yml`      |
| Publications (hidden if empty) | `_data/publications.yml` |
| Interests                    | `_data/interests.yml`     |
| Look and feel                | `assets/css/style.css`    |
| Flow-field animation         | `assets/js/field.js`      |
